Was NOVA AI aktuell macht

Diese kostenlose Starterversion nutzt Canvas-Verarbeitung im Browser: Größenanpassung und einen einfachen Schärfefilter. Sie enthält noch kein trainiertes KI-Modell wie Topaz, keine echte KI-Rauschreduzierung und keine KI-Bildrekonstruktion. Für echtes KI-Upscaling wäre später ein Modell oder ein eigener Rechenserver nötig.

Deine ausgewählten Dateien werden von diesem Code nicht an einen Server hochgeladen.
